\chapter{Исследовательский раздел}

\section{Характеристики устройства и постановка исследования}

Исследования проводились на машине со следующими характеристиками:
\begin{itemize}[label=---]
	\item процессор Intel(R) Core(TM) i5-10210U~\cite{intel_i5_10210u_specs}, тактовая частота 1.60 ГГц, 8 логических ядер;
	\item оперативная память: 16~ГБ;
	\item операционная система: Ubuntu 24.04 LTS~\cite{ubuntu_24_04_docs}.
\end{itemize}

Основной задачей исследования является определение зависимости времени выполнения основных этапов разработанного метода от числа словоформ во входном предложении. Замеры для каждого предложения состоящего из $N$ словоформ выполняются 500 раз, при этом полученные данные будут аппроксимированы методом наименьших квадратов.

Выбор степени полинома для аппроксимации полученных данных осуществлялся по методу наименьших квадратов. Время выполнения алгоритма построения таблицы составляющих таким образом было аппроксимировано полиномом третьей степени~\ref{eq:cyk}, алгоритма восстановления деревьев составляющих~---~полиномом четвертой степени~\ref{eq:trees} соответственно.
\begin{equation}
	\label{eq:cyk}
	T_{table}(n)\approx 7.85\exp{-6}n^3 - 1.29\exp{-4}n^2 + 1.01\exp{-3}n - 1.56\exp{-3}
\end{equation}
\begin{equation}
	\label{eq:trees}
	T_{trees}(N)\approx -1.19\exp{-8}n^4 +  5.5\exp{-7}n^3 - 8.29\exp{-6}n^2 + 4.12\exp{-5}n - 3.49\exp{-6}
\end{equation}

\section*{Выводы}

По результатам проведенного исследования видно, что наиболее долгим этапом в разработанном методе является восстановление деревьев составляющих. В общем случае с ростом числа словоформ во входном предложении растет также число восстановленных деревьев зависимостей. Отсутствие монотонности в данной зависимости объясняется различиями в синтаксической структуре исходных предложений использованных в ходе исследования. Аппроксимация времени выполнения алгоритма построения таблиц составляющих полиномом третьей степени соответствует асимптотике исходного алгоритма CYK $O(n^3)$.
